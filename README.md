# Pixel Editor 🎨

초보자도 바로 쓸 수 있는 **픽셀아트 & 애니메이션 에디터**입니다.
최종 목표는 [PixelOver](https://pixelover.io)의 모든 기능 + 더 쉬운 애니메이션 작업 기능을 갖춘 **상용 수준 프로그램**입니다.

> 지금은 **1단계(기본 에디터 + 프레임 애니메이션)** 가 완성된 상태입니다.
> 전체 계획은 [docs/ROADMAP.md](docs/ROADMAP.md) 를 보세요.

---

## 1. 실행하는 방법 (처음이라면 이것부터!)

### ① Node.js 설치
- https://nodejs.org 에서 **LTS 버전(22 이상)** 을 설치합니다.
- 설치 확인: 터미널(명령 프롬프트)에서
  ```bash
  node -v   # v22.x.x 처럼 나오면 성공
  npm -v
  ```

### ② 프로젝트 내려받기 & 라이브러리 설치
```bash
git clone https://github.com/CHOVB/pixel-editor.git
cd pixel-editor
npm install        # 필요한 라이브러리를 node_modules 폴더에 설치 (처음 한 번만)
```

### ③ 개발 서버 실행
```bash
npm run dev
```
터미널에 나오는 주소(보통 `http://localhost:5173`)를 **크롬 또는 엣지**로 엽니다.
코드를 고치고 저장하면 화면이 **자동으로 새로고침** 됩니다.

### 자주 쓰는 명령어

| 명령어 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 (코드 수정 시 자동 반영) |
| `npm test` | 단위 테스트 실행 (그리기 알고리즘, 저장/불러오기 등 35개) |
| `npm run typecheck` | TypeScript 타입 오류 검사 |
| `npm run build` | 배포용 파일을 `dist/` 폴더에 생성 |
| `npm run preview` | 빌드된 결과물을 미리 실행 |

## 2. 지금 쓸 수 있는 기능 (1단계)

### 그리기 도구 (13종)
연필 · 지우개 · 채우기 · 스포이드 · 디더 브러시 · 직선 · 사각형 · 원/타원 · 사각형 선택 · 올가미 선택 · 마술봉 · 이동 · 손(화면 이동)

- **픽셀 퍼펙트**: 손으로 그은 선의 군더더기 픽셀을 자동 제거
- **좌우/상하 대칭 그리기**
- 브러시 크기(1~64) · 네모/동그라미 브러시
- 채우기: 이어진 영역 / 같은 색 전체, 허용 오차
- 선택 영역: 추가(Shift) · 빼기(Alt) · 반전 · 복사/잘라내기/붙여넣기 · 뒤집기
- 다른 프로그램에서 복사한 이미지 붙여넣기 (Ctrl+V)

### 레이어
추가 · 복제 · 삭제 · 순서 변경(끌어서 놓기) · 아래와 합치기 · 보이기/숨기기 · 잠그기 · 불투명도 · 이름 변경

### 애니메이션
- 프레임 추가 · 복제 · 삭제 · 순서 변경(끌어서 놓기) · 순서 뒤집기
- 프레임별 재생 시간(ms) / 전체 FPS 설정
- **어니언 스킨** (앞/뒤 프레임 반투명 표시, 장수·진하기·색조 조절)
- **애니메이션 태그** (예: "걷기" 1~6, "점프" 7~12) → 태그만 반복 재생
- 반복 / 왕복(핑퐁) / 한 번 재생
- 그리는 동안 계속 재생되는 **실시간 미리보기 창**

### 색 & 팔레트
- HSV 색 선택기 + 투명도 + HEX 입력
- 기본 팔레트 8종 (Endesga 32, PICO-8, Sweetie 16, DawnBringer 16/32, Game Boy, 흑백 등)
- 팔레트 파일 가져오기/내보내기 (`.hex` `.gpl` `.txt`)
- 그림에서 쓰인 색으로 팔레트 자동 생성, 밝기순 정렬

### 파일
- 프로젝트 저장/열기 (`.pxe`) – 크롬/엣지에서는 진짜 프로그램처럼 같은 파일에 덮어쓰기 저장
- **자동 저장** (15초마다) → 갑자기 꺼져도 시작 화면에서 복구
- 이미지 열기 / 이미지를 새 레이어로 가져오기 / 파일 끌어다 놓기
- 내보내기: **PNG**, **GIF 애니메이션**, **스프라이트시트 + JSON**(Aseprite 형식 호환, Unity/Godot 등에서 사용)
- 캔버스 크기 변경(기준 위치 선택) · 이미지 크기 조절 · 전체 뒤집기/회전

### 초보자 친화 UI
- 시작 화면 + 5단계 빠른 시작 안내
- 모든 버튼에 **설명 + 단축키 말풍선**, 도구별 사용법 힌트 표시
- 잠긴/숨긴 레이어에 그리려 하면 이유를 알려주는 안내 메시지
- **한국어 / English** 전환 (한글 입력 상태에서도 단축키 동작)
- 모든 작업 **실행 취소 / 다시 실행** (최대 300단계)

## 3. 폴더 구조 한눈에 보기

```
pixel-editor/
├─ index.html              # 웹페이지 뼈대
├─ src/
│  ├─ main.tsx             # 프로그램 시작점
│  ├─ App.tsx              # 화면 전체 배치 + 전역 이벤트(단축키, 붙여넣기, 드래그&드롭)
│  ├─ core/                # ★ 화면과 무관한 "순수 로직" (테스트 가능)
│  │  ├─ types.ts          #   데이터 구조 (프로젝트, 레이어, 프레임...)
│  │  ├─ color.ts          #   색 변환 (HEX, HSV ...)
│  │  ├─ pixels.ts         #   픽셀 버퍼 조작 (뒤집기, 회전, 크기 변경...)
│  │  ├─ drawing.ts        #   그리기 알고리즘 (직선, 타원, 채우기, 픽셀 퍼펙트)
│  │  ├─ history.ts        #   실행 취소/다시 실행
│  │  ├─ project.ts        #   레이어/프레임/태그 추가·삭제·이동
│  │  ├─ render.ts         #   레이어 합성
│  │  ├─ selection.ts      #   선택 영역 마스크
│  │  ├─ palettes.ts       #   기본 팔레트 + 팔레트 파일
│  │  ├─ exporters.ts      #   스프라이트시트 / GIF 만들기
│  │  └─ fileFormat.ts     #   .pxe 파일 저장 형식
│  ├─ store/               # ★ 앱 상태 관리 (Zustand)
│  │  ├─ editorStore.ts    #   공용 상태 (현재 도구, 색, 줌...)
│  │  ├─ actions.ts        #   버튼/메뉴가 실행하는 명령 + 실행 취소 기록
│  │  └─ prefs.ts          #   환경설정 저장
│  ├─ tools/               # ★ 그리기 도구들
│  ├─ editor/              #   단축키, 클립보드, 파일 동작, 화면 줌, 재생
│  ├─ components/          # ★ 화면(UI) 부품들 (React)
│  │  └─ dialogs/          #   대화상자들
│  ├─ platform/            #   브라우저 전용 기능 (파일 저장, 자동 저장소)
│  ├─ i18n/                #   한국어/영어 문구 사전
│  └─ styles/global.css    #   전체 디자인
├─ tests/                  # 단위 테스트
└─ docs/                   # 설계 문서 / 로드맵
```

더 자세한 설명은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) 에 있습니다.

## 4. 기술 스택

| 구분 | 사용 기술 | 이유 |
| --- | --- | --- |
| 언어 | TypeScript | 오류를 미리 잡아주는 "타입"이 있어 큰 프로그램에 안전 |
| 화면 | React 19 | 가장 널리 쓰이는 UI 라이브러리 → 자료가 많음 |
| 상태 관리 | Zustand | 배우기 쉽고 가벼움 |
| 빌드 도구 | Vite | 실행이 매우 빠름 |
| GIF 인코딩 | gifenc | 빠르고 작은 GIF 라이브러리 |
| 테스트 | Vitest | Vite 와 같은 설정으로 바로 테스트 |

웹 기술로 만들었기 때문에 나중에 **Tauri** 로 감싸서 Windows/Mac/Linux 설치형 프로그램으로 배포할 수 있습니다. (로드맵 6단계)

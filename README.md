# Pixel Editor 🎨

초보자도 바로 쓸 수 있는 **픽셀아트 & 도트 애니메이션 에디터**입니다.
[PixelOver](https://pixelover.io)의 2D 핵심 기능(레이어, 비파괴 효과, 키프레임, 뼈대/IK, 메시 변형, 파티클, 팔레트 작업)에
**애니메이션을 더 쉽게 만드는 기능**(자동 중간 프레임, VFX 추천, 파츠 분리 + 가려진 부분 채우기, AI 도트 정리)을 더했습니다.

> **1~6단계가 모두 완료**된 상태입니다. (3D 기능은 요청에 따라 제외 – 2D 전용)
> 단계별 내용과 남은 과제는 [docs/ROADMAP.md](docs/ROADMAP.md), 출시 방법은 [docs/RELEASE.md](docs/RELEASE.md) 를 보세요.

## 1. 실행하는 방법 (처음이라면 이것부터!)

### ① Node.js 설치
- https://nodejs.org 에서 **LTS 버전(22 이상)** 을 설치합니다.
- 설치 확인: 터미널(명령 프롬프트)에서 `node -v` → `v22.x.x` 처럼 나오면 성공

### ② 프로젝트 내려받기 & 라이브러리 설치
```bash
git clone https://github.com/CHOVB/pixel-editor.git
cd pixel-editor
npm install        # 필요한 라이브러리 설치 (처음 한 번만)
```

### ③ 실행
```bash
npm run dev
```
터미널에 나오는 주소(보통 `http://localhost:5173`)를 **크롬 또는 엣지**로 엽니다. 처음 화면의 **예제**나 **따라 하기 튜토리얼**부터 시작해 보세요.

### ④ (선택) AI 기능 – Codex 연결 (API 키 필요 없음)
AI 기능은 **OpenAI Codex CLI 를 ChatGPT 계정으로 로그인해서** 사용합니다.
```bash
npm install -g @openai/codex   # Codex CLI 설치 (한 번만)
codex login                    # 브라우저에서 ChatGPT 계정으로 로그인 (한 번만)
npm run codex-bridge           # 웹 버전: 에디터와 Codex 를 잇는 브리지 실행 (데스크톱 앱은 필요 없음)
```
에디터 오른쪽 위 **🤖 Codex** 버튼에서 연결 상태를 확인할 수 있습니다.

### 자주 쓰는 명령어

| 명령어 | 하는 일 |
| --- | --- |

## 2. 기능 한눈에 보기

### 그리기 (1단계)
연필 · 지우개 · 채우기 · 스포이드 · 디더 · 직선 · 사각형 · 타원 · 사각형/올가미/마술봉 선택 · 이동 · 손 ·
**변형(T)** · **뼈대 만들기(J)** · **자세 잡기(P)** / 픽셀 퍼펙트, 대칭, 브러시 크기·모양, 선택 영역 편집

### 애니메이션 (2단계)
- 레이어 × 프레임 **셀 타임라인**, 어니언 스킨(앞/뒤 장수, 처음↔끝 잇기, 기준 프레임 고정), 태그, 반복/왕복
- **키프레임 움직임**: 변형 도구로 옮기고 돌리면 자동으로 키 → 사이는 **이징 곡선 9종**(곡선 직접 편집)으로 보간
- **RotSprite** 도트 회전, **링크 셀**(한 장 고치면 함께 바뀜), 레이어 **그룹 · 블렌드 모드 10종**
- **밑그림**: 스케치 레이어(내보내기에서 자동 제외) + 레퍼런스 이미지
- **⭐ 자동 중간 프레임**: 서 있기 → 다리 벌리기 2장만 그리면 사이 6장을 자동 생성 (모양 이어주기 / 디더 전환 / **AI(Codex)**), 돌아오는 동작까지 한 번에
- GIF · 스프라이트시트 가져오기(칸 자동 분리), 반복 타일 미리보기
- **프레임 일괄 변형(Alt+T)**: 고른 프레임/전체를 한 번에 이동(반대편 잇기)·뒤집기·회전, 링크 유지 / Shift+H·V 도 범위 전체에 적용
- 어니언 스킨 **"바뀌는 프레임만"**: 홀드가 긴 애니메이션에서 새 그림·키프레임이 있는 프레임만 비춰 보기

### 효과 · 자연 효과 · 외곽선 (3단계)
- 원본을 바꾸지 않는 **효과 스택**: 외곽선, 그림자, 색 보정, 팔레트 맞추기, 색 줄이기, 디더링 6종, 도트화, 단색 덮기, **컬러 사이클링**, 팔레트 스왑
- **자연 효과** 원클릭: 머리카락 흔들림 · 풀/나무 바람 · 깃발 · 물결 · 숨쉬기 · 둥실둥실 · 피격 흔들림 · 무적 깜빡임
- **외곽선 · 정리**: 흰 테두리, 검은 외곽선, 자동 셀아웃, 번짐/외톨이 점/구멍/계단 정리
- **⭐ 효과 값 키프레임**: ◆ 를 찍고 프레임을 옮겨 값만 바꾸면 자동 키 (예: 하얗게 100% → 0% 로 "번쩍 → 사라짐", 흔들림 세기 점점 크게). 원클릭 프리셋 포함
- **⭐ AI 도트 이미지 정리**: 고해상도 AI 이미지에서 영역 선택 → **도트 격자 자동 감지** → 1도트=1픽셀로 축소(또는 64·32 등 지정) → 얼룩 색 합치기 → 팔레트 보정 → 배경 제거

### 뼈대 (4단계)
- 뼈 계층, **IK**(끝을 끌면 팔 전체가 따라옴), 통째로/휘어지게(메시 가중치) 연결, 자동 연결, 뼈 키프레임
- **⭐ 파츠 분리 + 가려진 부분 채우기**: 머리·팔 등을 떼어내면 몸통의 빈 곳을 자동(주변 색) 또는 **Codex** 로 채움

### 파티클 · VFX (5단계, 2D 전용)
- 파티클 레이어 8종(비·눈·낙엽·불꽃·연기·반짝임·먼지·마법), 같은 프레임은 항상 같은 결과(반복 애니메이션용)
- **⭐ VFX 추천**: 동작을 분석해 착지(먼지) · 타격 · 빠른 휘두르기(베기) · 빠른 이동(속도선) · 점프 꼭대기(반짝임) 프레임을 찾아 바로 넣기

### 출시 준비 (6단계)
- **데스크톱 앱(Tauri)**: Windows/macOS/Linux, `.pxe`/`.aseprite` 파일 연결, 앱 안에서 Codex 직접 실행
- **웹 앱(PWA)**: 설치 · 오프라인 실행, 파일 연결
- **Aseprite(.aseprite/.ase) 열기·저장**, 최근 파일, 자동 저장 간격 설정
- **환경설정**: 언어, 어두운/밝은/시스템 테마, 화면 크기, **단축키 바꾸기**
- **따라 하기 튜토리얼 9단계 + 예제 4종**, 오류가 나도 작업을 지키는 **복구 화면**
- GIF 만들기는 **Web Worker** 에서 (큰 그림도 화면이 멈추지 않음)
- **GPU(WebGL2) 화면 합성**: 레이어 섞기를 그래픽카드로 → 큰 캔버스·레이어가 많아도 부드럽게 (안 되면 CPU 자동 전환, 설정에서 선택)
- **자동 업데이트(데스크톱)**: 하루 한 번 새 버전 확인 → 서명 확인 후 설치 → 다시 시작
- **오류 보고(사용자 동의 시에만)**: 개인 정보(이메일·폴더 경로)를 지운 오류 내용만 전송, 기본은 꺼짐
- **코드 서명 자동화**: 인증서를 저장소 비밀값에 넣으면 Windows(PFX/Azure)·macOS(공증) 서명된 설치 파일이 만들어짐
- **라이선스 키**(오프라인 확인, 기능 제한 없음) + 발급 도구
- 자동 점검: 단위 테스트, 브라우저 E2E, Rust 테스트, GitHub Actions(CI · 데스크톱 릴리스)

## 3. 폴더 구조 한눈에 보기

```
pixel-editor/
├─ src/
│  ├─ core/        ★ 화면과 무관한 순수 로직 (테스트 가능)
│  │               그리기·합성(render)·키프레임·이징·RotSprite·효과·뼈대/IK·중간 프레임·
│  │               인페인팅·AI 도트 정리(pixelfix)·VFX·파티클·정리(cleanup)·Aseprite·파일 형식
│  ├─ store/       ★ 앱 상태(Zustand) + 실행 취소되는 명령들 (actions / anim / bone / effect / tool)
│  ├─ tools/       ★ 그리기·선택·이동·변형·뼈대 도구
│  ├─ editor/      단축키(사용자 설정), 파일, 최근 파일, 예제, 오류 대비, 내보내기 Worker 연결
│  ├─ ai/          Codex 연동 (브리지 / 데스크톱 명령) + 결과를 도트로 정리
│  ├─ licensing/   라이선스 키 확인
│  ├─ workers/     Web Worker (GIF 만들기)
│  ├─ components/  화면 부품 (React) + dialogs/ 대화상자
│  ├─ platform/    브라우저/데스크톱 전용 기능 (파일 대화상자, 저장소, GPU 합성, 업데이트, 오류 보고)
│  └─ i18n/        한국어/영어 사전
├─ bridge/         웹 버전용 Codex 브리지 (Node, 내 컴퓨터에서만 열림)
├─ src-tauri/      데스크톱 앱 (Rust) + crates/codex_core (Codex 연동, 단독 테스트 가능)
├─ scripts/        라이선스 키 · 업데이트 키 · 출시 설정 · 오류 보고 예제 서버 · 홍보 영상 도구
├─ tests/          단위 테스트 (Vitest)      e2e/  브라우저 점검 (Playwright)
├─ public/         아이콘, PWA manifest, 서비스 워커
└─ docs/           설계(ARCHITECTURE) · 로드맵(ROADMAP) · 출시(RELEASE)
```

더 자세한 설명은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) 에 있습니다.

## 4. 기술 스택

| 구분 | 사용 기술 | 이유 |
| --- | --- | --- |
| 언어 | TypeScript, Rust(데스크톱) | 타입으로 오류를 미리 잡음 / 작고 빠른 데스크톱 앱 |
| 화면 | React 19 + Canvas 2D + WebGL2 | 자료가 많고 배우기 쉬움 / 레이어 합성은 GPU 로 빠르게 |
| 상태 관리 | Zustand | 배우기 쉽고 가벼움 |
| 빌드 | Vite | 실행이 매우 빠름, Web Worker · 코드 분할 지원 |
| 데스크톱 | Tauri 2 | 설치 파일이 작음(수 MB), Windows/macOS/Linux |
| AI | OpenAI Codex CLI (ChatGPT 로그인) | API 키 없이 ChatGPT 요금제로 이미지 생성 |
| 테스트 | Vitest, Playwright, cargo test | 로직 / 실제 화면 / Rust |

# 개발 로드맵

목표: **PixelOver 의 모든 기능 + 더 쉬운 애니메이션 작업 기능**을 갖춘 상용 픽셀아트 애니메이션 프로그램

PixelOver 의 핵심 기능(공식 소개 기준)
- 레이어 기반 작업 + 그리기 도구(연필, 지우개, 채우기, 선택)
- 비파괴 실시간 픽셀아트 효과: 색 인덱싱(팔레트 맞추기), 디더링, 픽셀 리샘플링, 픽셀 퍼펙트 선(외곽선)
- 키프레임 애니메이션 (변형, 그리기, 셰이더 값 등 거의 모든 것)
- 뼈대(본) 리깅, 역운동학(IK), 픽셀아트용 메시 변형
- 이미지/GIF/3D 모델(메시, 재질, 애니메이션, 본) 가져오기, 3D 카메라/조명/재질 편집
- 고급 파티클 시스템
- 팔레트 작업: 매치 인덱싱, 컬러 사이클링
- 이미지 시퀀스 / GIF / 스프라이트시트 내보내기 (3D 회전 자동 내보내기 포함)

아래처럼 **한 단계씩** 쌓아 올립니다. 각 단계가 끝날 때마다 "실제로 쓸 수 있는 프로그램" 상태를 유지합니다.

---

- [x] 픽셀 퍼펙트, 대칭 그리기, 브러시 크기/모양
- [x] 레이어 (추가/복제/삭제/순서/합치기/숨기기/잠금/불투명도)
- [x] 프레임 애니메이션 (프레임별 시간, FPS, 반복/왕복/한 번)

## 2단계 – 애니메이션 작업을 쉽게 만드는 기능 ⭐ (다음 작업)

- [ ] **키프레임 트윈(중간 프레임 자동 생성)**: 레이어의 위치/회전/크기/투명도를 키프레임으로 지정하면 사이 프레임을 자동 계산
- [ ] **이징 곡선 편집기** (천천히 시작/끝, 튕기기 등 + 그래프로 직접 조절)
- [ ] **RotSprite 픽셀아트 회전**: 회전해도 픽셀이 뭉개지지 않는 알고리즘
- [ ] 링크된 셀 (여러 프레임이 같은 그림을 공유 → 한 번 고치면 모두 반영)
- [ ] 프레임 범위 일괄 작업 (이동, 색 교체, 뒤집기)
- [ ] 어니언 스킨 고급 (키프레임만 보기, 특정 프레임 고정)
- [ ] 레퍼런스 이미지 레이어 (밑그림 띄우기)
- [ ] 타일 모드 미리보기 (반복 패턴 확인), 셀 단위 썸네일 타임라인
- [ ] GIF / 스프라이트시트 가져오기 (프레임 자동 분리)
- [ ] 레이어 그룹, 블렌드 모드

## 3단계 – PixelOver 핵심: 비파괴 픽셀아트 효과

- [ ] 효과 스택 시스템 (레이어마다 효과를 쌓고 언제든 수정/제거 – 원본 보존)

- [ ] 픽셀 리샘플링 (고해상도 그림 → 픽셀아트 변환)
- [ ] 외곽선 / 안쪽 선 / 그림자 효과, 색 조정(명도/채도/색상)
- [ ] 컬러 사이클링, 팔레트 스왑 애니메이션
- [ ] WebGL 렌더러로 전환 (효과를 실시간으로 빠르게)

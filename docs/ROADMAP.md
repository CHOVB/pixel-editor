# 개발 로드맵

목표: **PixelOver 의 2D 기능 + 더 쉬운 애니메이션 작업 기능**을 갖춘 상용 픽셀아트 애니메이션 프로그램
(요청에 따라 3D 모델 기능은 제외하고 **2D 전용**으로 만듭니다.)

PixelOver 의 핵심 기능(공식 소개 기준)과 이 프로그램의 대응
- 레이어 기반 작업 + 그리기 도구 → ✅
- 비파괴 실시간 효과: 색 인덱싱, 디더링, 픽셀 리샘플링, 픽셀 퍼펙트 외곽선 → ✅ (효과 스택)
- 키프레임 애니메이션 → ✅ 레이어 변형 · 뼈대 자세 · 효과 값
- 뼈대 리깅, IK, 픽셀아트 메시 변형 → ✅
- 이미지/GIF 가져오기 → ✅ (3D 모델 가져오기는 ❌ 제외)
- 파티클 시스템 → ✅ 2D 파티클 레이어
- 팔레트 작업(매치 인덱싱, 컬러 사이클링) → ✅
- 이미지 시퀀스 / GIF / 스프라이트시트 내보내기 → ✅ (+ Aseprite)

표시: ✅ 완료 · 🟡 일부 완료(남은 부분 설명) · ❌ 하지 않기로 함 · 🔑 판매자가 직접 준비할 것(인증서 구매·키 등록 – 코드는 준비 완료)

---

## ✅ 1단계 – 기본 픽셀 에디터 + 프레임 애니메이션

- ✅ 그리기 도구 13종, 픽셀 퍼펙트, 대칭, 브러시 크기/모양
- ✅ 레이어, 프레임 애니메이션, 어니언 스킨, 태그, 실시간 미리보기
- ✅ 팔레트(8종 + 파일 가져오기/내보내기), 실행 취소, 클립보드, 선택 영역
- ✅ 저장/열기(.pxe), 자동 저장 & 복구, PNG/GIF/스프라이트시트+JSON 내보내기
- ✅ 한국어/영어, 시작 화면, 말풍선 도움말

## ✅ 2단계 – 애니메이션 작업을 쉽게

- ✅ 키프레임 트윈 (위치/회전/크기/불투명도) + 변형 도구 오토 키
- ✅ 이징 9종 + 곡선 직접 편집 (cubic-bezier)
- ✅ RotSprite 도트 회전
- ✅ 링크 셀 (복제 시 링크 옵션 포함)
- ✅ 레이어 그룹, 블렌드 모드 10종
- ✅ 밑그림: 스케치 레이어(내보내기 제외) + 레퍼런스 이미지 레이어
- ✅ 레이어 × 프레임 셀 타임라인, 반복 타일 미리보기
- ✅ GIF / 스프라이트시트 가져오기
- ✅ **자동 중간 프레임** (모양 이어주기 / 디더 전환 / AI-Codex), 돌아오는 동작 포함
- ✅ 어니언 스킨: 처음↔끝 잇기, 기준 프레임 고정
- ✅ 여러 프레임 색 바꾸기
- ✅ 프레임 일괄 변형(Alt+T): 고른 범위/전체 · 현재/모든 레이어 · 이동(반대편 잇기)·뒤집기·회전, 링크 유지, 잠긴 레이어 건너뜀
- ✅ Shift+H / Shift+V 가 고른 프레임 범위 전체에 적용
- ✅ 어니언 스킨 "바뀌는 프레임만 (키프레임)" – 새 그림·변형 키·뼈 키·효과 키가 있는 프레임만

## ✅ 3단계 – 비파괴 효과 · 자연 효과 · 도트 정리

- ✅ 효과 스택 (레이어마다 쌓기/끄기/순서/삭제, 원본 보존)
- ✅ 팔레트 맞추기(지각 색 거리), 색 줄이기(Median Cut), 디더링 6종(Bayer 2/4/8, Floyd, Atkinson)
- ✅ 도트화(리샘플링), 외곽선(안/밖, 대각선, 자동 셀아웃), 그림자, 색 보정, 컬러 사이클링, 팔레트 스왑
- ✅ **자연 효과**: 흔들림(머리카락/풀/깃발/물결), 숨쉬기, 둥실, 흔들기, 깜빡임 + 원클릭 프리셋
- ✅ **외곽선 · 정리 도구**: 흰 테두리, 번짐 제거, 외톨이 점, 구멍, 계단
- ✅ **AI 도트 이미지 정리**: 영역 선택 → 격자 자동 감지 → 1도트=1픽셀(또는 64/32 지정) → 얼룩 색 합치기 → 팔레트 → 배경 제거 → 시트 나누기
- ✅ WebGL2 화면 합성: 레이어 텍스처 캐시(바뀐 레이어만 업로드) + 블렌드 10종 셰이더, CPU 자동 전환, 설정·상태바 표시
  (GPU↔CPU 결과 차이 2/255 이하를 E2E 로 확인). 그룹·프레임 합성 캐시 + 메모리 한도(384MB) 추가.
  효과 계산 자체(외곽선·디더 등)는 아직 CPU 이지만 결과 캐시로 한 번만 계산합니다.

## ✅ 4단계 – 뼈대 애니메이션 & 메시 변형

- ✅ 뼈 만들기 / 계층 / 뼈 키프레임 + 이징
- ✅ IK (CCD 방식, 따라오는 뼈 수 조절)
- ✅ 통째로(rigid) / 휘어지게(mesh, 격자 + 거리 가중치) 연결, 자동 연결
- ✅ **파츠 분리 + 가려진 부분 채우기** (자동 알고리즘 / Codex)
- ✅ 움직임/뼈대/효과를 그림으로 굽기
- ✅ 효과 값 키프레임: 숫자 설정마다 키 + 이징, 자동 키, 타임라인 보라 ◆, 저장/불러오기, 원클릭 프리셋(번쩍→사라짐, 어둠에서 나타나기)

## ✅ 5단계 – 2D 파티클 & VFX (3D 제외)

- ❌ 3D 모델 가져오기 / 3D 카메라·조명 – 요청에 따라 제외
- ✅ 파티클 레이어 8종 (결정적: 같은 프레임 = 같은 결과)
- ✅ **VFX 추천** (착지/타격/휘두르기/이동/꼭대기) + 절차적 VFX 5종 + 프레임 자동 늘리기

## ✅ 6단계 – 상용 출시 준비

- ✅ **Tauri 2 데스크톱 앱** (Windows/macOS/Linux), `.pxe`/`.aseprite` 파일 연결, 운영체제 파일 대화상자, 앱 안에서 Codex 직접 실행
- ✅ **PWA** (설치 · 오프라인 실행 · 파일 연결)
- ✅ 최근 파일, 자동 저장 간격 설정
- ✅ Web Worker 로 GIF 만들기, 큰 대화상자 코드 분할(첫 실행 빠르게)
- ✅ 환경설정: 테마(어둡게/밝게/시스템), 화면 크기, **단축키 사용자 설정**(충돌 검사)
- ✅ **따라 하기 튜토리얼 9단계 + 예제 4종**
- ✅ **Aseprite(.aseprite/.ase) 열기·저장** (32/16/8비트, 그룹, 링크 셀, 태그, 블렌드)
- ✅ 오류 복구 화면 + 비상 자동 저장 + 오류 내용 복사
- ✅ 라이선스 키 (오프라인 확인 + 발급 도구), 기능 제한 없음
- ✅ 테스트: 단위(Vitest) · 브라우저(Playwright) · Rust(cargo test), GitHub Actions(CI · 데스크톱 릴리스)
- ✅ 자동 업데이트(데스크톱): 하루 한 번 확인 · 업데이트 대화상자 · 진행 막대 · 다시 시작, 서명 확인(변조 파일 거부 시험 완료),
  릴리스 작업이 서명된 업데이트 파일과 latest.json 을 자동 업로드 — 🔑 `npm run updater:keygen` 한 번 + 비밀값 등록
- ✅ 오류 보고: 기본 꺼짐, 설정/오류 화면에서 동의 시에만 전송, 개인 정보 지우기, 중복·횟수 제한, 보내는 내용 미리 보기, 예제 수신 서버
  — 🔑 받을 서버 주소(ERROR_REPORT_URL)만 정하면 됨
- ✅ 코드 서명 자동화: Windows(PFX 인증서 또는 Azure Trusted Signing) · macOS(서명+공증) — 🔑 인증서는 판매자 명의로 구매 후 비밀값 등록
